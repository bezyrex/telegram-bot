# BotFather Commands

Paste the block below into [@BotFather](https://t.me/BotFather) with `/setcommands`, then pick your bot.

```text
start - Bot info and command list
help - List all commands
ps - List containers (docker ps -a)
psa - List containers (alias of ps)
inspect - Show container details
logs - Show recent container logs
top - Show processes inside container
exec - Run a command inside a container
start_c - Start a container
stop - Stop a container
restart - Restart a container
rm - Remove a container (force)
stats - CPU, memory and network usage
images - List Docker images
pull - Pull a Docker image
df - Show disk usage
compose - Run docker compose in a project path
protected - Show protected container names
```
